INSTRUCCIONES — Fuentes JetBrains Mono
======================================

Para que la estética brutalista funcione correctamente, coloca aquí los archivos TTF de JetBrains Mono:

  JetBrainsMono-Regular.ttf
  JetBrainsMono-Bold.ttf

Descarga gratuita (SIL Open Font License):
  https://www.jetbrains.com/lp/mono/
  https://github.com/JetBrains/JetBrainsMono/releases

Si no se incluyen los archivos TTF, la app usará Consolas como fuente de fallback del sistema.
No se distribuyen en el repositorio por cuestiones de tamaño; añádelos manualmente antes de compilar.
